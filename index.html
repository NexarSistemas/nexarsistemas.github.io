Preguntas frecuentes

Lo esencial, antes de empezar

¿Necesito conocimientos técnicos para usar los productos?

No. Las aplicaciones están pensadas para un uso simple y cotidiano.

¿En qué sistemas operativos funcionan?

Nexar Comercio y Nexar Finanzas se comunican actualmente como soluciones locales para Windows y Linux.

¿Qué producto corresponde a un negocio?

Nexar Comercio está orientado a ventas, stock, caja, clientes, proveedores y reportes comerciales.

¿Realizan webs para profesionales?

Sí. Diseñamos landing pages y sitios institucionales para profesionales como odontólogos, médicos, abogados, contadores, arquitectos, ingenieros y otros prestadores de servicios.

¿Las webs tienen un precio fijo?

No. Cada proyecto se presupuesta según su alcance, cantidad de secciones, contenido y funcionalidades necesarias.
