Preguntas Frecuentes

Respuestas rápidas sobre el ecosistema Nexar.

¿Qué producto necesito para un comercio?

Para ventas, stock, caja, clientes, proveedores y reportes comerciales corresponde Nexar Comercio.

¿Qué producto necesito para ordenar mis gastos personales?

Para organizar ingresos, gastos, cuentas, presupuestos y reportes personales corresponde Nexar Finanzas.

¿Funcionan sin internet?

Sí. Los productos se comunican como sistemas locales para PC, pensados para operar sin depender de conexión permanente.

¿Tienen versión para celular?

No. Actualmente las apps de Nexar no se comunican como versiones móviles. La propuesta disponible es local para PC.

¿Los datos se guardan en la nube?

No se presenta como función disponible hoy. La nube todavía no está implementada y los productos se comunican como soluciones locales.
